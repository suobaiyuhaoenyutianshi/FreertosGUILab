## 三、讲解顺序（按依赖，不按周）

1. **底座**：F08（优先级模型）→ F01（切换机制）→ F03（栈）→ F05（周期）→ F06（事件驱动）。
   先把“任务怎么被调度、栈怎么算、周期怎么保证、事件怎么通知”这条线打通，后面的调试卡才有落点。
2. **调试**：D01（抓现场）→ D03（读 CFSR）→ D09（看门狗）→ D10（掉线检测）。
3. **外设**：C01（CAN 位时序）→ C05（串口 DMA+IDLE）→ C08（I2C 连读）。
4. **工程**：E01（git）→ E04（CMake）→ L01（日志检索）。

## 四、每张卡统一结构（背的时候按这个顺序）

1. **一句话答案**：面试官问完，你先给结论。
2. **原理链**：为什么会这样，3~5 步。
3. **项目证据**：文件:行 + 这段代码在干什么。面试时能说出“我项目里在哪一行”最加分。
4. **追问与答法**：每卡 2~3 个高频追问。
5. **翻车点**：最容易答错的那一句。
6. **30 秒口述骨架**：4~6 个关键词，卡住时按关键词往下展开。

## 五、你“老是卡”的三个真实原因（先治这个）

1. **背的是结论，没背顺序**。本套每卡最后都给“口述骨架”，先背骨架再填肉。
2. **概念对没有落到数字**。比如“栈 384 字”要能立刻换成 1536B；“IWDG 500ms”要能现场算 PR×RLR。
3. **两个优先级模型混用**。任务优先级“数值大=高”，中断优先级“数值小=高”，这是你模拟面试里唯一的硬伤（见 `CARTESTFreertos/面试评分总结.md` Q2）。本套会反复用同一句话钉死。
